# Dusty Dragon M36-M45 — Symbol Curriculum to MT5 Training Gate

This phase turns the M0-M35 research architecture into a symbol-conditioned training system without granting broker-write authority.

## Permanent laws

- The internet supplies hypotheses, not truth.
- Acquisition must answer a measured research question or knowledge gap.
- Dusty must consume its curriculum before expanding it.
- Popularity controls discovery priority, never statistical confidence.
- Exact-symbol evidence outranks transfer evidence; transfer must remain explicitly labeled.
- Public performance is a claim until independently reproduced.
- MT5 is the higher-fidelity arbiter when research and tester results materially disagree.
- Broker writes remain unauthorized through M45.

## Milestones

| Milestone | Capability | Gate |
|---|---|---|
| M36 | Symbol curriculum discovery | exact-symbol, as-of-date cohorts; default top-N is 20; broker suffix aliases require explicit verification |
| M37 | Curriculum compression | exact duplicates and strategy-family variants are counted rather than mistaken for independent evidence |
| M38 | Trading knowledge vocabulary | concepts and tool relations must be explicitly supported by source-derived material |
| M39 | Human-reasoning bridge | only bounded point-in-time-valid curriculum enters EvidenceSnapshot; cross-asset transfer is opt-in |
| M40 | Bounded hypothesis composer | combines already-understood declarative rules, preserves ancestry, never generates executable source code |
| M41 | Self-development tournament | experiments collapse into compact promising/rejected/untested lessons |
| M42 | Adaptive curriculum + regime learning | new acquisition requires a knowledge gap and consumed backlog; regime cardinality is bounded |
| M43 | Read-only MT5 worker | lazy MetaTrader5 history adapter, chunked UTC bar retrieval, official command-line tester configuration with live trading disabled |
| M44 | Multi-fidelity validation | Open Prices -> 1 Minute OHLC -> Every Tick -> Real Ticks only advances after reconciliation |
| M45 | Training-phase certification | may certify readiness to develop demo execution; broker_write_authorized remains false |

## Source cohorts

For an active symbol such as EURUSD, Forex Factory and Myfxbook contribute raw top-gain, research-ranked, and failure/control cohorts. TradingView additionally contributes a popularity-ranked cohort because popularity is useful for finding widely reused strategy ideas. Quantpedia, QuantConnect, GitHub, papers, and later sources enter the same provenance and symbol-conditioning pipeline.

Headline portfolio gain is not automatically treated as target-symbol gain. A strategy/account belongs in an exact-symbol cohort only when normalized source material attributes the observation to that symbol. Otherwise it remains portfolio-level or transfer evidence.

## MT5 boundary

The M43 worker deliberately exposes historical bars and Strategy Tester launch/configuration only. It contains no order-send method and does not accept broker credentials. The generated tester configuration sets `AllowLiveTrading=0`, disables DLL import, remote/cloud agents, optimization, and visual mode, and uses the MetaTrader 5 documented model mapping: 0 Every Tick, 1 1 Minute OHLC, 2 Open Prices, 4 Real Ticks.
